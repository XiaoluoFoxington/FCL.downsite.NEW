keyboard_arrow_down

Fold Craft Launcher (FCL for short) lets you run Minecraft: Java Edition on Android devices and supports various mod loaders. In addition, it offers many powerful features such as automatic installation, managing multiple game versions, and downloading mods and modpacks.

This is an unofficial FCL distribution download station built by the player community. Since the GFW blocks FCL's GitHub links, many players cannot download the latest FCL. We provide fast and safe direct download links.
