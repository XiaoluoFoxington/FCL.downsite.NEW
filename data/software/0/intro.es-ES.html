¿Qué es esto?
keyboard_arrow_down

Fold Craft Launcher (FCL para abreviar) te permite ejecutar Minecraft: Java Edition en dispositivos Android y admite varios cargadores de mods. Además, ofrece muchas funciones potentes, como la instalación automática, la gestión de varias versiones del juego y la descarga de mods y paquetes de mods.

Esta es una estación de descargas de la distribución de FCL construida espontáneamente por la comunidad de jugadores. Dado que el GFW bloquea los enlaces de GitHub de FCL, muchos jugadores no pueden descargar la última versión de FCL. Ofrecemos enlaces directos rápidos y seguros.

Código abierto
keyboard_arrow_down

Este software es de código abierto en GitHub. Puedes ver el código fuente libremente y te garantizamos que no contiene ningún código malicioso. Es un software seguro y limpio.

Gestión de versiones del juego
keyboard_arrow_down

Descarga e instala versiones del juego automáticamente, admite cargadores de mods e incluye gestión de versiones del juego.

Descarga de recursos integrada
keyboard_arrow_down

Además de las versiones del juego, también puedes descargar paquetes de mods, mods, paquetes de recursos, mundos y shaders.

Alta compatibilidad
keyboard_arrow_down

Ya incluye soporte para Java 8, Java 11, Java 17 y Java 21. El lanzador selecciona automáticamente la versión de Java según la versión del juego.

Sistema de diseño de controles
keyboard_arrow_down

Crea tus propios diseños de controles o descarga los creados por otros jugadores desde el repositorio de diseños. Puedes disfrutar de una buena experiencia de juego incluso sin teclado físico.
