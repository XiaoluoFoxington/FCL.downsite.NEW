Qu'est-ce que c'est ?
keyboard_arrow_down

Fold Craft Launcher (ci-après FCL) est un logiciel qui vous permet d'exécuter Minecraft : Java Edition sur appareils Android et qui prend en charge divers chargeurs de mods. Il offre en outre de nombreuses fonctionnalités puissantes telles que l'installation automatique, la gestion de plusieurs versions du jeu, ou encore le téléchargement de mods et de packs de mods.

Ceci est un site de téléchargement de la distribution FCL, monté spontanément par la communauté de joueurs. Le GFW bloquant les liens GitHub de FCL, de nombreux joueurs ne peuvent pas télécharger la dernière version de FCL. Nous fournissons des liens directs rapides et sûrs.

Fonctionnalités
keyboard_arrow_down
Open source
keyboard_arrow_down

Ce logiciel est open source sur GitHub. Vous pouvez consulter librement le code source, et nous garantissons l'absence de tout code malveillant. C'est un logiciel propre et sûr.

Gestion des versions du jeu
keyboard_arrow_down

Téléchargement et installation automatiques des versions du jeu, prise en charge des chargeurs de mods, et gestion intégrée des versions du jeu.

Téléchargement de ressources intégré
keyboard_arrow_down

Outre les versions du jeu, vous pouvez également télécharger des packs de mods, des mods, des packs de ressources, des mondes et des shaders.

Forte compatibilité
keyboard_arrow_down

Prise en charge intégrée de Java 8, Java 11, Java 17 et Java 21. Le launcher sélectionne automatiquement la version de Java en fonction de la version du jeu.

Système de disposition des contrôles
keyboard_arrow_down

Créez vos propres dispositions de contrôles ou téléchargez celles créées par d'autres joueurs depuis le dépôt de dispositions. Vous pouvez profiter d'une bonne expérience de jeu même sans clavier physique.
