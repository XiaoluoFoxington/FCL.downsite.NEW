Что это такое?
keyboard_arrow_down

Fold Craft Launcher (сокращённо — FCL) позволяет запускать Minecraft: Java Edition на устройствах Android и поддерживает различные загрузчики модов. Кроме того, он предлагает множество мощных функций, таких как автоматическая установка, управление несколькими версиями игры и загрузка модов и модпаков.

Это неофициальный сайт загрузки дистрибутивов FCL, созданный сообществом игроков. Поскольку GFW блокирует ссылки FCL на GitHub, многие игроки не могут загрузить последнюю версию FCL. Мы предоставляем быстрые и безопасные прямые ссылки для загрузки.

Возможности
keyboard_arrow_down
Открытый исходный код
keyboard_arrow_down

Это программное обеспечение имеет открытый исходный код на GitHub. Вы можете свободно просматривать исходный код, и мы гарантируем отсутствие вредоносного кода. Это безопасное и чистое программное обеспечение.

Управление версиями игры
keyboard_arrow_down

Автоматически загружает и устанавливает версии игры, поддерживает загрузчики модов и включает управление версиями игры.

Встроенные загрузки ресурсов
keyboard_arrow_down

Помимо версий игры, вы также можете загружать модпаки, моды, наборы ресурсов, миры и шейдеры.

Высокая совместимость
keyboard_arrow_down

Встроены Java 8, Java 11, Java 17 и Java 21. Загрузчик автоматически выбирает версию Java в зависимости от версии игры.

Система раскладок управления
keyboard_arrow_down

Создавайте собственные раскладки управления или загружайте раскладки, созданные другими игроками, из хранилища раскладок. Вы сможете наслаждаться отличным игровым опытом даже без физической клавиатуры.
