# MDUI 1.0.2 主题系统迁移指南

> 适用场景：把本站（FCL 下载站）基于补丁方式实现的 MDUI 1.0.2 主题系统，迁移到另一个同样使用
> `mdui@1.0.2`（CDN 引用）的站点。
>
> 前提：目标站点必须使用 **MDUI 1.0.2** 及其公开类名/变量约定（`mdui-theme-layout-*`、`mdui-theme-primary-*`、
> `mdui-theme-accent-*`、`--mdui-color-*`）。这套系统的机制只依赖公开 API，不依赖本站特有 DOM 结构，
> 因此核心逻辑可原样复用；需要调整的只是命名与设置页壳子。

---

## 1. 机制速览

- 用户偏好（`auto` / `light` / `dark` + 主色 + 强调色）存于 `localStorage`。
- JS（`js/domain/theme.js`）把偏好写成 MDUI 官方类名挂到 `<body>`，同时计算**最终主题**
  （`auto` 结合 `matchMedia('(prefers-color-scheme: dark)')` 解析）写入 `<html data-xf-theme>`。
- 本站补丁 CSS 只认 `html[data-xf-theme="dark"]` 一个值来决定深浅色，不再写媒体查询与 layout 类的组合判断。
- 官方 `mdui.min.css` 负责组件内部配色（仍走 `mdui-theme-layout-*` 类），补丁 CSS 只做视觉层覆盖。

## 2. 迁移文件清单

### 2.1 必迁（主题系统本体）

| 文件 | 作用 | 依赖 |
|------|------|------|
| `css/mdui.theme.enhanced.css` | 主题色补色板（950 色号）、每主题色的 `--mdui-bg` / `--mdui-bg-dark`、body / drawer / 面板的深浅色背景应用 | 无 |
| `css/mdui.patch.css` | MDUI 细节补丁（drawer 宽度、面板边距、深色阴影、表格边框与悬停等），含深色规则 | 无 |
| `js/domain/theme.js` | `applyTheme` + `syncResolvedTheme`（最终主题计算与属性写入） | `./preferences.js` |
| `js/common/theme.js` | 页面入口：立即应用主题、系统主题变化监听、设置页 radio 绑定 | `domain/theme.js`、`domain/preferences.js`、`views/uiComponents.js`（仅设置页）、`views/commonView.js`（仅设置页） |

### 2.2 必迁（依赖模块）

| 文件 | 作用 | 说明 |
|------|------|------|
| `js/domain/preferences.js` | localStorage 安全读写封装（兼容隐私模式） | 若目标站已有等价封装，可替换 `theme.js` 中的 import |

### 2.3 可选（设置页专用）

| 文件 | 作用 | 说明 |
|------|------|------|
| `html/theme.html` | 主题设置页面模板 | 只迁移 radio 结构即可，见第 4 节 |
| `js/views/uiComponents.js` | `showSnackbar`（保存成功提示） | 依赖 `window.mdui.snackbar`；不需要提示可裁剪 |
| `js/views/commonView.js` | `debounce`（保存提示防抖） | 文件顶部含 `SITE_NAME = 'FCL 下载站'` 常量需改；也可自写三行 debounce 替代 |

> 不需要设置页时，`js/common/theme.js` 可精简为「立即应用 + 系统主题监听」两个动作（约 15 行），
> 从而完全去掉对 `uiComponents.js` / `commonView.js` 的依赖。

## 3. 必须修改的配置项

### 3.1 localStorage 键（三处）

`js/domain/theme.js` 与 `js/common/theme.js` 中出现的 `fdn-theme`、`fdn-theme-primary`、`fdn-theme-accent`
（`fdn` 为本站前缀）。若目标站希望独立于本站的本地存储，请全局替换为新前缀，如：

```js
readPreference('fdn-theme')            // → 'your-site-theme'
writePreference('fdn-theme', 'auto')   // 同理
```

### 3.2 `<html>` 属性名 `data-xf-theme`（一处 JS + 全部 CSS）

- JS：`js/domain/theme.js` 中 `document.documentElement.dataset.xfTheme = ...`
- CSS：以下文件里所有 `html[data-xf-theme="dark"]` 选择器：
  - `css/mdui.theme.enhanced.css`（3 处：body 背景、面板、drawer）
  - `css/mdui.patch.css`（9 处：按钮阴影 ×3、面板阴影、表格边框 ×4、表格悬停）
  - `css/xf.css`（1 处：自定义表头悬停；仅当迁移该文件时）

改名时务必保证 JS 的 `dataset` 键与 CSS 选择器同步。例如改名 `data-site-theme`：
`dataset.siteTheme` ↔ `html[data-site-theme="dark"]`。

### 3.3 默认值

`js/domain/theme.js` 的 `applyTheme` 中：

```js
const themeValue = theme || readPreference('fdn-theme') || 'auto';   // 默认跟随系统
const primaryValue = primary || readPreference('fdn-theme-primary') || 'teal';
const accentValue = accent || readPreference('fdn-theme-accent') || 'green';
```

主色 / 强调色默认值可换成目标站想要的 MDUI 颜色名（见 `html/theme.html` 中的合法 value 列表）。

### 3.4 `<body>` 初始类

目标站每个页面的 `<body>` 需要带 `mdui-theme-layout-auto` 初始类，否则首帧前 MDUI 自身配色不生效：

```html
<body class="mdui-appbar-with-toolbar mdui-container-fluid mdui-theme-layout-auto">
```

### 3.5 CSS / JS 加载顺序

```html
<link rel="stylesheet" href="https://unpkg.com/mdui@1.0.2/dist/css/mdui.min.css">
<link rel="stylesheet" href="/css/mdui.theme.enhanced.css">
<link rel="stylesheet" href="/css/mdui.patch.css">
<link rel="stylesheet" href="/css/xxx.css">   <!-- 站点自定义样式，放最后 -->

<script src="https://unpkg.com/mdui@1.0.2/dist/js/mdui.min.js"></script>
<script type="module" src="/js/common.js"></script>
```

- 补丁 CSS 必须在官方 `mdui.min.css` **之后**加载：补丁与官方规则特异性持平时靠加载顺序取胜。
- `mdui.min.js` 需在 `common.js` 之前（`showSnackbar` 用到 `window.mdui.snackbar`）。
- `js/common.js`（站点模块入口）需要 `import './common/theme.js';`，或直接引入该文件。

### 3.6 深色背景色值（可选自定义）

- `--mdui-color-*-950`：为深色背景自研的暗色色号，由官方 900 色经 HSL 降明度生成（亮度 ≈0.06，
  与白字对比度 ≥ 9.0，满足 WCAG AAA）。若目标站接受现有配色，可完全不改。
- 每个主题色块（`body.mdui-theme-primary-*`）内的 `--mdui-bg`（浅色背景，官方 100 色号）与
  `--mdui-bg-dark`（深色背景，900 或 950 色号）：想换背景基调时在此调整。

## 4. 设置页（可选）迁移要点

沿用 `js/common/theme.js` 的 radio 绑定，目标站的设置页 DOM 必须满足以下约定：

| 容器 id | radio name | 合法 value |
|---------|-----------|-----------|
| `theme-select` | `theme-layout` | `auto` / `light` / `dark` |
| `primary-select` | `theme-primary` | MDUI 全部主题色名（amber、blue、teal……） |
| `accent-select` | `theme-accent` | MDUI 全部强调色名（同色名集合） |

- 三个容器 id 是硬编码约定（`common/theme.js` 中 `restoreRadioState` / `bindRadioEvent` 使用）。
- radio 结构可直接照抄 `html/theme.html` 的 `mdui-panel` 片段。
- 切换即即时预览：`change` 事件触发 `applyTheme()` → 写 `data-xf-theme` → 全站立即变色。

## 5. 验证清单

迁移完成后逐项验证：

- [ ] 无偏好（默认）时：系统浅色 → `data-xf-theme="light"`、浅色背景；系统深色 → `data-xf-theme="dark"`、深色背景
- [ ] 强制 `light` / `dark` 后刷新，主题保持且 `data-xf-theme` 正确
- [ ] `auto` 模式下切换系统深浅色，页面实时跟随
- [ ] 设置页 radio 初始选中状态与已保存偏好一致；切换后即时生效并弹出保存提示
- [ ] 深色下：面板 / drawer 背景、按钮与面板阴影、表格边框与悬停均为深色适配
- [ ] 清除 `localStorage` 后刷新，恢复默认 `auto`
- [ ] 浏览器控制台无与本系统相关的 JS 报错

## 6. 常见坑

- **改了属性名只改一半**：JS 的 `dataset` 键必须与 CSS 选择器一一对应，漏改任何一处深浅色即失效。
- **加载顺序颠倒**：补丁 CSS 若在官方 `mdui.min.css` 之前，同特异性规则会被官方覆盖，深色补丁不生效。
- **localStorage 键冲突**：直接沿用 `fdn-*` 键会导致目标站与本站共享同一份偏好，迁移时建议改名。
- **MDUI 版本不一致**：本系统只对 1.0.2 的行为（类名、变量、`mdui-theme-layout-*` 语义）做过验证，升级大版本需重新验证。
