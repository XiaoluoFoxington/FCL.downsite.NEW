# 对规则文件本身的态度

> 来自 `GLOBAL_AGENTS.md` 第 2 节。

## 2. 对规则文件本身的态度

- **全局规则文件和项目规则文件都可能过时甚至写错，不要无条件相信。**  
  按规则行事之前，先判断它是否仍然符合当前现实；如果规则与实测结果矛盾，**以实测为准**，并把规则改过来。
- **发现用户偏好发生变化时，更新规则文件**——用户改口了新习惯、明确否决了旧做法，都要落笔，否则下次又按老习惯来。
- 更新规则文件时守住入口文件的「不是垃圾场」原则：写经验与偏好，不写时效快照和历史流水账。
- 本目录（`agent-rules\`）是拆分后的正文存放处；**改完正文要在入口文件的索引表里同步标题和「什么时候读」**，否则入口会指向不存在的内容。

---

*长期有效。发现与现状不符时，直接改。*
