# 交互规则

> 来自 `GLOBAL_AGENTS.md` 第 1 节。往这里补充前先读入口文件的「规则文件不是垃圾场」原则。

## 1. 交互规则

- **遇到不确定或需要决策的事，直接问用户。**  
  唯一的例外是用户明确说了「别问我任何问题」「无人值守」「我睡觉去了」之类的话。  
  没有这句豁免，就**不要擅自做决定**。
  - ⚠️ 这条同样管**运行环境**：**能自己判断出来的就自己判断**（环境变量、工作目录、进程特征等都是证据）。
  - 问的时候把选项和取舍讲清楚，别丢一个开放式问题让人猜。
  - 不要吝啬提问工具，不要觉得问用户那么多问题用户会不耐烦。
- 在做大改动时，先把规划告诉用户，再动手。
- 注意单位使用的准确性。
  用户不希望看到单位混用，特别是计算文件大小时使用1024进制却使用了SI单位。
