# i18n 国际化使用与维护指南

## 1. 概述

FCL 下载站的 i18n 系统支持多语言界面切换，当前支持简体中文（zh-CN）和英语（en-US）。系统具有以下特性：

- **容错优先**：翻译键缺失时按语言顺序回退，绝不抛错影响站点可用性
- **DOM 自动翻译**：通过 `data-i18n` 属性自动翻译 HTML 元素
- **动态内容翻译**：通过 `t()` 函数翻译 JavaScript 动态生成的内容
- **语言顺序**：支持设置语言优先级列表，实现多语言回退机制
- **偏好持久化**：语言偏好保存在 localStorage 中，刷新后自动恢复

## 3. 核心 API

### 3.1 翻译函数 `t(key, params?, skip?)`

翻译指定的键，支持参数替换和占位符保留。

```javascript
import { t } from './common/i18n.js';

// 基本翻译
t('common.loading');
// → '正在加载……'

// 带参数的翻译
t('common.sortBy', { text: '名称' });
// → '按 名称 排序'

// 带占位符保留的翻译（用于混合内容场景）
t('common.nav.sponsorNotice', { sponsor: '<a>赞助</a>' }, new Set(['sponsor']));
```

**参数说明：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `key` | `string` | 翻译键，使用点号分隔的嵌套路径，如 `common.nav.announcement` |
| `params` | `object` | 可选。参数映射，用于替换翻译文本中的 `{param}` 占位符 |
| `skip` | `Set<string>` | 可选。需要保留原样的参数名集合，用于 DOM 占位符场景 |

### 3.2 DOM 翻译 `applyTranslations(root?)`

扫描 DOM 并翻译带有 `data-i18n` 属性的元素。

```javascript
import { applyTranslations } from './common/i18n.js';

// 翻译整个页面
applyTranslations();

// 翻译指定容器（动态插入的内容）
const container = document.querySelector('#dynamic-content');
applyTranslations(container);
```

### 3.3 动态内容翻译 `translateDynamicContent(container)`

用于翻译动态插入的内容，如抽屉、公告等。

```javascript
import { translateDynamicContent } from './common/i18n.js';

// 加载动态内容后调用
const drawer = document.querySelector('#drawer');
translateDynamicContent(drawer);
```

### 3.4 语言管理

```javascript
import {
    getCurrentLang,
    getLanguageOrder,
    setLanguageOrder,
    getSupportedLanguages,
} from './common/i18n.js';

// 获取当前界面语言
getCurrentLang();  // → 'zh-CN'

// 获取语言顺序（第一位为界面语言，其余为回退）
getLanguageOrder();  // → ['zh-CN', 'en-US']

// 设置语言顺序
setLanguageOrder(['en-US', 'zh-CN']);  // 切换到英文，中文作为回退

// 获取所有支持的语言
getSupportedLanguages();
// → [{code: 'zh-CN', name: '简体中文'}, {code: 'en-US', name: 'English'}]
```

### 3.5 其他工具函数

```javascript
import {
    translateTag,
    tOr,
    getLocalizedPath,
} from './common/i18n.js';

// 翻译标签名（数据源中的中文标签）
translateTag('启动器');  // → 'Launchers'（如果有翻译），否则返回 '启动器'

// 带回退的翻译（用于数据源内容）
tOr('software.description', '原始中文描述');
// → 翻译值或回退到 '原始中文描述'

// 获取本地化资源路径
getLocalizedPath('/data/announcement.html');
// 当前为英文时 → '/data/announcement.en-US.html'
// 当前为中文时 → null
```

## 4. HTML 静态内容国际化

### 4.1 基本文本翻译

在 HTML 元素上添加 `data-i18n` 属性，值为对应的翻译键：

```html
<!-- 翻译文本内容 -->
<button data-i18n="common.confirm">确认</button>

<!-- 页面标题 -->
<title data-i18n="list.pageTitle">资源列表 - FCL下载站</title>
```

页面加载时，`initI18n()` 会自动扫描并翻译所有带 `data-i18n` 的元素。

### 4.2 属性翻译

使用 `data-i18n-attr` 指定要翻译的属性：

```html
<!-- 翻译 title 属性 -->
<span data-i18n="common.tooltip" data-i18n-attr="title" title="提示">
    ℹ️
</span>

<!-- 翻译 alt 属性 -->
<img data-i18n="logo.alt" data-i18n-attr="alt" src="logo.png" alt="FCL 下载站">

<!-- 翻译 content 属性（用于 meta 标签） -->
<meta data-i18n="home.description" data-i18n-attr="content" name="description" content="FCL下载站">
```

### 4.3 带参数的翻译

使用 `data-i18n-params` 传递 JSON 格式的参数：

```html
<!-- 翻译: "按 名称 排序" -->
<button data-i18n="common.sortBy" data-i18n-params='{"text":"名称"}'>
    按 名称 排序
</button>

<!-- 翻译: "显示 5 个被筛选条件隐藏的项目" -->
<div data-i18n="common.hiddenItems" data-i18n-params='{"count":5}'>
    显示 5 个被筛选条件隐藏的项目
</div>
```

### 4.4 混合内容翻译（含 HTML 子元素）

当翻译文本中需要保留 HTML 子元素时，直接子元素上的 `data-i18n` 会被视为占位符：

- `data-i18n="some.key"`：子元素会被翻译，父模板中用 `{some.key}` 占位
- `data-i18n="[name]"`：子元素不翻译，父模板中用 `{name}` 占位

```html
<!-- 子元素需要翻译：data-i18n 值为完整 key，父模板中 key 即占位符名 -->
<p data-i18n="sponsor.disclaimer2">
    赞助为<mark data-i18n="sponsor.voluntary">纯自愿</mark>。不赞助也能正常使用网站。请结合您的经济状况实力再考虑是否要赞助。赞助后<mark data-i18n="sponsor.nonRefundable">无法退款</mark>。
</p>
```

对应的语言包配置：
```javascript
{
    sponsor: {
        disclaimer2: '赞助为{sponsor.voluntary}。不赞助也能正常使用网站。请结合您的经济状况实力再考虑是否要赞助。赞助后{sponsor.nonRefundable}。',
        voluntary: '纯自愿',
        nonRefundable: '无法退款',
    }
}
```

```html
<!-- 子元素不需要翻译：data-i18n="[name]"，父模板中用 {name} 占位 -->
<p data-i18n="notFound.whatDesc">
    HTTP 响应状态码 <code data-i18n="[code]">404 Not Found</code> 指的是服务器无法找到所请求的资源。
</p>
```

对应的语言包配置：
```javascript
{
    notFound: {
        whatDesc: 'HTTP 响应状态码 {code} 指的是服务器无法找到所请求的资源。'
    }
}
```

## 5. JavaScript 动态内容国际化

```javascript
import { t } from './common/i18n.js';

import { tOr, translateTag } from './common/i18n.js';

```

import { translateDynamicContent } from './common/i18n.js';

async function loadDrawer() {

## 6. 语言包结构

### 6.1 模块组织

语言包按功能模块组织，使用嵌套对象结构：

```javascript
const zhCN = {
    // 通用文本（所有页面共用）
    common: {
        siteName: 'FCL 下载站',
        loading: '正在加载……',
        nav: {
            announcement: '网站公告',
            resourceList: '资源列表',
        },
    },

    // 标签翻译（数据源中的中文标签）
    tags: {
        '启动器': '启动器',
        '插件': '插件',
    },

    // 线路名称翻译
    mirror: {
        0: '线路1',
        1: '线路2',
    },

    // 详情页消息（按软件 ID 和序号寻址）
    detailMessage: {
        5: { 0: 'Krypton Wrapper 更改了应用签名……' },
        7: { 0: '已停止更新……' },
    },

    // 各页面模块
    home: { /* ... */ },
    list: { /* ... */ },
    detail: { /* ... */ },
    about: { /* ... */ },
    behavior: { /* ... */ },
    theme: { /* ... */ },
    rh: { /* ... */ },      // 版本历史
    intro: { /* ... */ },  // 介绍文档
    sponsor: { /* ... */ },
    sponsorRemind: { /* ... */ },
    language: { /* ... */ },
    notFound: { /* ... */ },
    template: { /* ... */ },
};
```

### 6.2 键命名规范

- 使用**小写字母**和**点号分隔**的嵌套路径
- 按模块组织：`common.nav.announcement`、`list.header.name`
- 动态内容使用占位符：`common.sortBy`（值为 `按 {text} 排序`）
- 避免使用特殊字符作为键名

### 6.3 参数占位符

在翻译文本中使用 `{paramName}` 格式表示可变内容：

```javascript
{
    common: {
        sortBy: '按 {text} 排序',
        hiddenItems: '显示 {count} 个被筛选条件隐藏的项目',
    }
}
```

调用时传入对应参数：
```javascript
t('common.sortBy', { text: '名称' });
t('common.hiddenItems', { count: 5 });
```

## 7. 添加新翻译条目

### 7.1 新增静态文本翻译

**步骤：**

1. 在语言包的对应模块中添加键值对
2. 在 HTML 元素上添加 `data-i18n` 属性
3. 确保所有语言包（zh-CN.js 和 en-US.js）都添加对应条目

**示例：**

假设要为列表页新增一个「批量下载」按钮：

**第一步：在 zh-CN.js 添加**
```javascript
list: {
    // ... 现有内容
    batchDownload: '批量下载',  // 新增
}
```

**第二步：在 en-US.js 添加**
```javascript
list: {
    // ... existing
    batchDownload: 'Batch Download',  // new
}
```

**第三步：在 HTML 中使用**
```html
<button data-i18n="list.batchDownload">批量下载</button>
```

### 7.2 新增动态文本翻译

如果文本是通过 JavaScript 动态生成的，只需在代码中使用 `t()` 函数：

```javascript
import { t } from './common/i18n.js';

// 语言包：common.exportData = '导出数据'
button.textContent = t('common.exportData');

// 带参数：list.filteredCount = '已筛选 {count} 项'
button.textContent = t('list.filteredCount', { count: items.length });
```

### 7.3 新增标签翻译

如果数据源中添加了新标签，需要在 `tags` 模块中添加翻译：

```javascript
tags: {
    // ... 现有标签
    '新标签名': '新标签名',  // zh-CN
}
```

```javascript
tags: {
    // ... existing tags
    '新标签名': 'New Tag',  // en-US
}
```

## 8. 添加新语言

### 8.1 创建语言包文件

在 `js/i18n/` 目录下创建新的语言包文件，例如 `ja-JP.js`：

```javascript
/**
 * 日本語パック

const jaJP = {

        siteName: 'FCL ダウンロードステーション',
        loading: '読み込み中……',
        // ... 翻译所有条目
    },
    // ... 其他模块

export default jaJP;
```

### 8.2 注册语言包

在 `js/common/i18n.js` 中：

**第一步：添加导入**
```javascript
import zhCN from '../i18n/zh-CN.js';
import enUS from '../i18n/en-US.js';
import jaJP from '../i18n/ja-JP.js';  // 新增
```

**第二步：注册到 LANGUAGE_PACKS**
```javascript
const LANGUAGE_PACKS = {
    'zh-CN': zhCN,
    'en-US': enUS,
    'ja-JP': jaJP,  // 新增
};
```

**第三步：添加语言显示名称**
```javascript
export const LANGUAGE_NAMES = {
    'zh-CN': '简体中文',
    'en-US': 'English',
    'ja-JP': '日本語',  // 新增
};
```

**第四步：更新浏览器语言检测**
```javascript
function detectBrowserLang() {
    const lang = String(navigator.language || navigator.userLanguage || 'zh-CN').toLowerCase();
    if (lang.startsWith('zh')) return 'zh-CN';
    if (lang.startsWith('en')) return 'en-US';
    if (lang.startsWith('ja')) return 'ja-JP';  // 新增
    return 'zh-CN';
}
```

### 8.3 完整性检查

确保新语言包包含**所有**现有键。可以通过以下方式检查：

- 对比两个语言包的键结构
- 使用脚本来验证键的完整性

## 10. 回退机制

### 10.1 语言回退顺序

系统支持设置语言优先级列表，按顺序回退：

```javascript
// 第一位为界面语言，其余为回退语言
setLanguageOrder(['en-US', 'zh-CN']);
// 翻译时先查 en-US，找不到再查 zh-CN，最后返回键本身
```

### 10.2 回退逻辑

```
翻译 key
    ↓
查找 languageOrder[0]（界面语言）
    ↓ 找不到
查找 languageOrder[1]（第一回退）
    ↓ 找不到
...（依次回退）
    ↓ 全部找不到
返回 key 本身
```

### 10.3 实际应用

当某个翻译键在当前语言中缺失时：
- 如果有回退语言，则使用回退语言的翻译
- 如果所有语言都没有，则显示键名本身（如 `common.loading`）

这确保了站点在翻译不完整时仍然可用。

## 11. 语言偏好存储

### 11.1 存储位置

语言偏好保存在 localStorage 中：

| 键名 | 格式 | 说明 |
|------|------|------|
| `fdn-language-order` | JSON 数组 | 语言顺序，如 `["zh-CN", "en-US"]` |
| `fdn-language` | 字符串 | 旧版单值偏好（兼容用） |

### 11.2 读取逻辑

```javascript
function loadLanguageOrder() {
    // 1. 尝试读取新格式（数组）
    const saved = readPreference('fdn-language-order');
    if (saved) {
        const parsed = JSON.parse(saved);
        if (Array.isArray(parsed)) return normalizeLanguageOrder(parsed);
    }
    
    // 2. 尝试读取旧格式（单值）
    const legacy = readPreference('fdn-language');
    if (legacy) {
        const order = normalizeLanguageOrder([legacy]);
        writePreference('fdn-language-order', JSON.stringify(order));
        return order;
    }
    
    // 3. 根据浏览器语言生成默认顺序
    return normalizeLanguageOrder([detectBrowserLang()]);
}
```

### 11.3 浏览器语言检测

```javascript
function detectBrowserLang() {
    const lang = navigator.language || navigator.userLanguage || 'zh-CN';
    if (lang.startsWith('zh')) return 'zh-CN';
    if (lang.startsWith('en')) return 'en-US';
    return 'zh-CN';  // 默认中文
}
```

## 12. 初始化流程

### 12.1 入口调用

在页面入口文件中调用 `initI18n()`：

```javascript
// common.js 或各页面入口
import { initI18n } from './common/i18n.js';

// 初始化 i18n
await initI18n();
```

### 12.2 初始化步骤

```
initI18n()
    ↓
读取保存的语言偏好 / 检测浏览器语言
    ↓
设置 currentLang 和 languageOrder
    ↓
设置 document.documentElement.lang
    ↓
等待 DOM 就绪
    ↓
applyTranslations() 翻译整个页面
    ↓
完成
```

### 12.3 执行时机

- 如果 DOM 已就绪，立即执行翻译
- 如果 DOM 尚未加载，监听 `DOMContentLoaded` 事件后执行

### 12.4 用户界面

用户可通过**语言设置页**管理语言偏好：

- **页面入口**：[html/language.html](../html/language.html)（导航抽屉 → 网站设置 → 语言设置）
- **逻辑模块**：[js/language.js](../js/language.js)（语言顺序排序、保存、预览）

语言设置页支持：
- 查看当前语言顺序
- 拖拽或使用上下按钮调整语言优先级
- 实时预览翻译效果
- 自动保存偏好到 localStorage

## 13. 常见场景处理

### 13.1 翻译动态加载的内容

```javascript
import { translateDynamicContent } from './common/i18n.js';

// 加载模板
async function loadTemplate(url, containerId) {
    const response = await fetch(url);
    const html = await response.text();
    const container = document.querySelector(`#${containerId}`);
    container.innerHTML = html;
    
    // 翻译新内容
    translateDynamicContent(container);
}
```

### 13.2 翻译后动态更新的内容

```javascript
import { t } from './common/i18n.js';

// 数据变化时更新文本
function updateStatus(newStatus) {
    statusElement.textContent = t(`status.${newStatus}`);
}
```

### 13.3 条件翻译

```javascript
import { t, tOr } from './common/i18n.js';

// 有翻译就用翻译，没有就用原文
const displayName = tOr(`software.${id}.displayName`, originalName);
```

### 13.4 翻译包含 HTML 的文本

当翻译文本中需要嵌入 HTML 时，直接通过参数替换即可，不需要使用 `skip` 参数：

```javascript
import { t } from './common/i18n.js';

// 翻译文本中包含链接
// 语言包: sponsorNotice: '请考虑 {sponsor} 或者帮忙宣传！'
const html = t('common.nav.sponsorNotice', {
    sponsor: `<a href="/sponsor">${t('common.nav.sponsorSite')}</a>`
});
// 结果: '请考虑 <a href="/sponsor">赞助站长</a> 或者帮忙宣传！'
```

> **注意**：`skip` 参数仅用于 DOM 占位符元素场景（见第 4.4 节），用于保留占位符标记以便后续插入子元素。在字符串拼接场景中不需要使用。

## 14. 维护规范

### 14.1 添加新文本时

1. **确定模块**：找到对应的功能模块（common、list、detail 等）
2. **命名键名**：使用小写字母和点号分隔，语义清晰
3. **同步更新**：必须在所有语言包中添加对应翻译
4. **使用占位符**：动态内容使用 `{param}` 格式，不要拼接字符串

### 14.2 键命名建议

```
{module}.{submodule}.{description}

示例：
common.nav.announcement      → 通用/导航/公告
list.header.sortByName        → 列表/表头/按名称排序
detail.basicInfo.systemReq    → 详情/基本信息/系统需求
```

### 14.3 翻译完整性检查

建议在提交代码前检查：

- [ ] 新增的翻译键是否在所有语言包中都有对应条目？
- [ ] 参数占位符（如 `{count}`）在各语言版本中是否一致？
- [ ] 键名是否符合命名规范？
- [ ] 是否有遗漏的硬编码文本需要国际化？

### 14.4 避免的陷阱

1. **不要在语言包中使用变量或表达式**：语言包必须是静态的纯对象
2. **不要在翻译文本中嵌套翻译键**：保持翻译的原子性
3. **不要假设翻译一定存在**：使用 `tOr()` 处理可能缺失的翻译
4. **不要在键名中使用特殊字符**：只使用小写字母、数字和点号

## 16. 扩展功能

> ⚠️ **注意**：本节内容为**假设性的扩展建议**，描述的是未来可能的增强方向，而非当前已实现的功能。在实施前请充分评估对现有系统的影响。

### 16.1 语言检测增强

可以在 `detectBrowserLang()` 中添加更多语言检测逻辑：

```javascript
function detectBrowserLang() {
    const lang = String(navigator.language || 'zh-CN').toLowerCase();
    if (lang.startsWith('zh')) return 'zh-CN';
    if (lang.startsWith('en')) return 'en-US';
    if (lang.startsWith('ja')) return 'ja-JP';
    if (lang.startsWith('ko')) return 'ko-KR';
    if (lang.startsWith('fr')) return 'fr-FR';
    return 'zh-CN';
}
```

### 16.2 自定义回退策略

如果需要更复杂的回退逻辑，可以修改 `t()` 函数：

```javascript
export function t(key, params = {}, skip = null) {
    try {
        for (const lang of languageOrder) {
            const value = getNestedValue(LANGUAGE_PACKS[lang], key);
            if (value !== undefined) return interpolate(value, params, skip);
        }
        // 自定义回退：如果所有语言都缺失，尝试使用默认语言
        const defaultValue = getNestedValue(LANGUAGE_PACKS['zh-CN'], key);
        if (defaultValue !== undefined) return interpolate(defaultValue, params, skip);
    } catch (error) {
        logWarn(error, `i18n 翻译失败: ${key}`);
    }
    return key;
}
```

### 16.3 翻译缓存

对于高频翻译场景，可以添加缓存优化：

```javascript
const translationCache = new Map();

export function t(key, params = {}, skip = null) {
    const cacheKey = `${currentLang}:${key}:${JSON.stringify(params)}`;
    if (translationCache.has(cacheKey)) {
        return translationCache.get(cacheKey);
    }
    
    const result = originalT(key, params, skip);
    translationCache.set(cacheKey, result);
    return result;
}

// 语言切换时清空缓存
export function clearI18nCache() {
    translationCache.clear();
}
```
